Submission repository for the Software 205 Training for Max Throttle Mavericks

Please make your own branch (with your first and last name), upload your 202 code, and modify it according to the requirements in the below slideshow in order to complete the requirements for the Software 205 Training. 
Note that this repository for ONLY THE MAX THROTTLE MAVERICKS, NOT MERCENARIES. They have a separate 205 training.
